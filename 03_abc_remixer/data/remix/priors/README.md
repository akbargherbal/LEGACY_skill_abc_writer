# Vendored prior snapshot

This directory is a fixed copy of the OSTRIS aggregate priors used by
`abc-score-writer`. It is kept here so `remix check` can report optional prior
percentiles without reading the sibling skill's `data/` directory at runtime.

It is **not** regenerated by the SUNO remixer build and does not describe the
670-score SUNO store. Treat it as advisory only; quote verification uses the
remixer store itself.
