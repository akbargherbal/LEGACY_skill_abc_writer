```bash
python3 analysis/calibrate_177.py \
  --corpus ~/Jupyter_Notebooks/OpenCode/arabmaqamrock/datasets/five_stars \
  --out analysis/out
```

| File | Contents |
|---|---|
| `summary.json` | Distributions, pass rates, A6 comparison, sanity gate set |
| `tracks.jsonl` | One row per track: raw metrics, gate verdicts, section match |

## OSTRIS corpus evidence

Generated by `make ostris-audit`, `make ostris-build`, `make ostris-features`,
and `make ostris-online` (the source cache is `ostris/source/` and the
canonical ABC work dir is `ostris/work/`, both ignored):

| File | Contents |
|---|---|
| `ostris/audit.json` | M0 inventory, link coverage, parse failures, quality flags, held-out list, gate checks |
| `ostris/audit.md` | M0 short human summary |
| `ostris/manifest_links.csv` | One row per library track (482 rows) |
| `ostris/records.jsonl` | One row per library track; canonical + features + ties |
| `ostris/held_out.jsonl` | The 35 YT500 transcripts not used by the library |
| `ostris/canonical.json` | M1 canonical coverage, contract pins, failures, meter/voice shapes |
| `ostris/canonical.md` | M1 short human summary |
| `ostris/features.json` | M2 feature coverage, key-relative mode families, limitations, gate checks |
| `ostris/features.md` | M2 short human summary |
| `ostris/priors/priors.json` | M3 objective priors index: 29 strata, meta, checks |
| `ostris/priors/<stratum>.json` | One prior file per stratum; every one `maqam_conditioned: false` |
| `ostris/priors/priors.md` | M3 human summary |
| `ostris/idioms.jsonl` | M4 structural phrases (1,304 rows; unreviewed) |
| `ostris/idioms.json` / `idioms.md` | M4 coverage and gate |
| `ostris/similarity/index.json` | M4 interval k-gram index |
| `ostris/similarity/similarity.json` | M4 index summary and gate |
| `ostris/eval/split.json` | M6 deterministic held-out split (14 generation + 17 retrieval) |
| `ostris/eval/report.json` | Written by `eval --runs` on demand; quality not evaluated |

The per-track canonical ABC text is reproducible under
`ostris/work/canonical/abc/` and is not committed.

The human registry is `02_maqam-score/references/numbers.md`; the
machine-readable thresholds are `02_maqam-score/scripts/calibration.json`.
The OSTRIS contracts are `02_maqam-score/schemas/`.
